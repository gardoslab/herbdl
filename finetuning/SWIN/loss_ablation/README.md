# Loss-function ablations (SWIN-Base, 384px)

Nine margin / hierarchical losses compared on Herbarium 2022 (15,501 species), then a
scaling ladder to 64k species. All training goes through
`finetuning/SWIN/SWIN_finetuning_advanced.py` + `train_advanced.sh` with a YAML config.

## Code (`finetuning/SWIN/loss_ablation/`)

| File | What it is |
|---|---|
| `losses.py` | Classifier heads: softmax, ArcFace / sub-center ArcFace, KappaFace, X2-Softmax, DBM |
| `hierarchy.py` | HACE (species / genus / family tree head) and `TaxonomyTree` |
| `aux.py` | Extra losses on top of a head: ECC, TARA (needs `bioclip_teacher.py`) |
| `grad_modulation.py` | FlexiGrad primitives (not wired into training yet) |
| `model.py` | `SwinWithLoss`: SWIN backbone + any head / hierarchy / aux combination |
| `checkpoint_io.py` | Geometry export used by `repgeom` (`mode: loss_ablation_geometry`) |
| `e2e_harness.py`, `*_smoke.py` | End-to-end and smoke tests (40 species, real images) |
| `build_ladder.py` | Builds the nested 15.5k / 32k / 64k species sets from the merged 2021+2022 data |
| `phase3_per_species.py` | Per-species F1 by rarity, error structure, paired bootstrap |
| `phase3_geometry.py` (+ `repgeom_geometry.py`) | Feature-space geometry per model (same metrics as repgeom) |
| `rare_crossover.py` | KappaFace vs DBM by training-image count, and the routing test |
| `run_*.sh` | SCC wrappers (env setup inside the script) |

## Trainer options added for this work (`SWIN_finetuning_advanced.py`)

- `hace:` and `loss_registry:` config sections (head, head_kwargs, aux, aux_log_steps)
- `training.resume_from_checkpoint: newest` (most recently saved checkpoint, not highest step)
- `training.max_steps` (fixed step budget; used by the scaling ladder)
- `evaluation.init_weights` / `predictions_path` / `features_path` (eval-only re-scoring)
- Multi-GPU evaluation now gathers predictions from all ranks (before this fix, 2-GPU runs
  were scored on half the validation set)

## Configs (`finetuning/SWIN/configs_advanced/`)

- `swin_base_384_*_pilot.yml`, `swin_base_384_arcface_ablation.yml`: one real-scale run per
  loss (`*_seed43.yml`: same run, seed 43; `swin_base_384_x2softmax_s64.yml`: scale 64)
- `swin_base_384_ladder_{n15k,n32k,n64k}_{dbm,arcface,kappaface}.yml`: scaling ladder
  (generated by `gen_ladder_configs.py`); `swin_base_384_ladder_smoke.yml`: 64k smoke test
- `phase3_eval/`, `phase3_geom/`: eval-only re-scoring configs (generated, see `generate.py`)

KappaFace and ECC must run on 1 GPU (per-species buffers are not synced across GPUs).

Results and the full write-up live in the project's tracking document
("Loss Function Ablations.md"), not in this repository.
